This is a Project (continuation form the previous repo, focusing on recreating the game for MigoYugo utilising unity) for making "artificial intelligence" to fight against.

the feature planned in this project would be:
- MigoYugo Gamerules
- 2 Player gameplay
- vsAI gameplay
- Clock mechanism


The AI that's going to be used is going to be using the Minimax algorithm, in which it would also use Alpha-Beta Pruning to make the player's gameplay comfortable.

(maybe if there's extra time, an API could be made.... probably not deployed though)
